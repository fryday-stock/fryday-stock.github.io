# نظام المخزن — خطوات التشغيل

## الملفات
| الملف | شنو بيه |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `app.js` | كل منطق النظام |
| `style.css` | الشكل |
| `config.js` | **الملف الوحيد اللي تعدله**: اسم المطعم + إعدادات Firebase |
| `firestore.rules` | قواعد حماية قاعدة البيانات |

## تجربة قبل النشر
افتح الموقع بدون ما تعبي إعدادات Firebase: يشتغل «وضع تجربة» والبيانات تنحفظ على نفس الجهاز فقط.

---

## الخطوة 1: قاعدة البيانات (Firebase) — مجانية
1. ادخل https://console.firebase.google.com بحساب Gmail.
2. **Add project** ← اكتب اسم (مثلاً `my-stock`) ← Google Analytics: Off ← Create.
3. من القائمة: **Build ← Firestore Database ← Create database** ← اختر موقع قريب (مثلاً `europe-west`) ← **Start in production mode**.
4. بنفس صفحة Firestore افتح تبويب **Rules**، امسح الموجود، والصق محتوى ملف `firestore.rules` ← **Publish**.
5. من القائمة: **Authentication ← Sign-in method ← Email/Password ← Enable ← Save**، وبعدها **Users ← Add user**: الإيميل `device@fryday.iq` وكلمة سر قوية (هذي كلمة سر المطعم لتفعيل الأجهزة). خلّي Anonymous مطفي.
6. اضغط ⚙️ **Project settings** ← بالأسفل **Your apps** ← اضغط أيقونة الويب `</>` ← اكتب اسم ← **Register app**.
7. راح يطلعلك كود بيه `firebaseConfig = { apiKey: ..., ... }`. انسخ القيم الست وحطها بملف `config.js`.

## الخطوة 2: نشر الموقع (GitHub Pages) — مجاني
1. سوّي حساب على https://github.com
2. **New repository** ← اسم مثلاً `stock` ← Public ← Create.
3. **Add file ← Upload files** ← اسحب كل الملفات ← **Commit changes**.
4. **Settings ← Pages** ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
5. بعد دقيقة يصير الرابط: `https://اسم-حسابك.github.io/stock/`

## الخطوة 3: أول تشغيل
1. افتح الرابط ← فعّل الجهاز بكلمة سر المطعم ← أنشئ حساب المدير (اسم + رمز).
2. **الإدارة ← أماكن الخزن**: أضف أماكنك.
3. **الإدارة ← المواد**: أضف المواد (الوحدة الأساسية، والكبيرة مع التعبئة إذا تحتاج، وحد الأمان).
4. **الإدارة ← الموظفين**: أضف كل موظف برمز خاص بيه.
5. **حركة جديدة ← رصيد افتتاحي**: سجّل الموجود حالياً بكل مكان مع سعره.
6. على التابلت: افتح الرابط بكروم ← القائمة ⋮ ← **Add to Home screen** حتى يصير مثل تطبيق.

## ملاحظات
- النظام يشتغل حتى لو انقطع الإنترنت لحظات، ويرفع الحركات أول ما يرجع.
- أي جهاز جديد يحتاج تفعيل بكلمة سر المطعم مرة وحدة. بدونها القاعدة ترفض أي قراءة أو كتابة حتى لو عنده الرابط.
- الرمز السري لكل موظف يمنعه يسجل باسم غيره.
- التعديل والحذف من **السجل** (للمدير، وللموظف إذا أعطيته الصلاحية من شاشة الموظفين). كل تعديل أو حذف ينسجل بشاشة **التعديلات والحذف**: منو، متى، شنو كان وشنو صار، والسبب. القاعدة ترفض أي تعديل ما ينسجل.
- النسخ الاحتياطي: **الإدارة ← النظام ← تنزيل نسخة احتياطية** كل أسبوع أو شهر.
